# Foursquare 游戏 - 手动测试计划

这份文档用于指导人工测试 Foursquare 游戏的所有已实现功能，包括 UI/UX、單機 AI 對戰和聯機對戰。

## 0. 测试环境

*   **设备**: 推荐使用真机（iOS/Android），也可使用模拟器。
*   **版本**: 最新构建的 Debug 或 Release 版本。
*   **服务端**: (仅联机测试需要) 确保 Wispbyte 服务端或本地 `npm start` 运行中。

---

## 1. UI 与 交互体验 (Phase 1 验收)

**重点**: 验证 "棋盘 UI 增强" 和 "音频系统" 的表现。

| ID | 测试项 | 操作步骤 | 预期结果 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| **1.1** | **主题切换** | 1. 进入设置页面。<br>2. 切换不同的"棋盘主题" (默认/现代/深色)。<br>3. 返回游戏页面。 | 1. 设置即时生效。<br>2. 棋盘背景、网格线颜色、棋子风格随主题改变。<br>3. 再次进入设置，选中的状态正确保留。 | [ ] |
| **1.2** | **音频控制** | 1. 进入设置页面。<br>2. 分别开关"音效"和"背景音乐"。<br>3. 调节音量滑块。 | 1. 关闭音效后，点击按钮/下棋无声音。<br>2. 关闭音乐后，BGM 立即停止。<br>3. 调节音量时能实时听到音量变化。 | [ ] |
| **1.3** | **动画效果** | 1. 在游戏中移动棋子。<br>2. 选中棋子。 | 1. 移动过程平滑 (EaseOutBack 曲线)，到达终点有微弱回弹。<br>2. 选中棋子时有持续的呼吸/脉动动画。 | [ ] |
| **1.4** | **冥想模式入口** | 主页点击"冥想模式" (如果已启用)。 | 正确进入冥想模式界面，或显示"开发中"提示 (视当前进度)。 | [ ] |

## 2. 单机 PVE (AI) 测试 (Phase 2 验收)

**重点**: 验证 AI 行为、游戏规则及撤销功能。

| ID | 测试项 | 操作步骤 | 预期结果 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| **2.1** | **AI 难度选择** | 1. 选择"人机对战"。<br>2. 选择"简单"难度开始游戏。 | 游戏开始，AI 响应速度较快 (<1秒)，走棋较为随机/简单。 | [ ] |
| **2.2** | **AI 回合逻辑** | 1. 玩家(黑)走棋。<br>2. 等待 AI(白)走棋。 | 1. 玩家走棋后，界面提示"AI 思考中"。<br>2. AI 在几秒内完成走棋。<br>3. 再次轮到玩家回合。 | [ ] |
| **2.3** | **撤销功能** | 1. 玩家走一步，AI 走一步。<br>2. 点击"撤销"按钮。 | 1. 棋盘回退两步 (玩家和 AI 的最后一步都撤销)。<br>2. 重新轮到玩家走棋。<br>3. 撤销过程有音效反馈。 | [ ] |
| **2.4** | **游戏结束(PVE)** | 构造一方获胜局面。 | 1. 弹出胜利/失败结算窗口。<br>2. 显示步数统计。<br>3. 点击"再来一局"可重置游戏。 | [ ] |
| **2.5** | **吃子规则(通用)** | 构造"己-己-敌"三子连线。 | 触发吃子动画，敌方棋子消失，播放吃子音效。 | [ ] |

## 3. 联机 PVP 测试 (Phase 3/4 预览)

**重点**: 验证客户端与服务端的连接、同步及异常处理。

| ID | 测试项 | 操作步骤 | 预期结果 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| **3.1** | **连接与匹配** | 1. 两台设备分别点击"在线对战" -> "开始匹配"。 | 1. 双方显示"匹配成功"。<br>2. 进入棋盘，分配好黑白执手。 | [ ] |
| **3.2** | **移动同步** | 玩家 A 移动棋子。 | 玩家 B 屏幕上几乎同时看到棋子移动。 | [ ] |
| **3.3** | **回合限制** | 轮到玩家 A 时，玩家 B 尝试操作。 | 玩家 B 无法移动棋子，或操作无效。 | [ ] |
| **3.4** | **吃子同步** | 玩家 A 触发吃子。 | 双方屏幕均显示棋子被吃掉，数量更新一致。 | [ ] |
| **3.5** | **断线/退出** | 游戏中途一方退出应用。 | 另一方收到对方断线或逃跑的提示，并判定获胜。 | [ ] |
