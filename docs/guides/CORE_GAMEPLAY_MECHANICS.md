# Foursquare (四子棋)

**最后更新**: 2026-01-12
**适用版本**: v0.1.0+

Foursquare 是一款在 4x4 棋盘上进行的零和策略棋类游戏。本指南采用**可视化**方式帮助您快速掌握规则。

---

## 1. 🏆 游戏目标 (Goal)
通过策略移动，**吃掉**对方的棋子。
*   **获胜条件**: 当对手剩余棋子 **≤ 1** 枚时，判定对手无力再战，我方获胜。

---

## 2. 🗺️ 棋盘与开局 (Setup)

游戏在 **4x4** 的网格上进行。
*   **⚫ 黑方 (先手)**: 占据顶端一行。
*   **⚪ 白方 (后手)**: 占据底端一行。

| 0 | 1 | 2 | 3 |
| :-: | :-: | :-: | :-: |
| ⚫ | ⚫ | ⚫ | ⚫ |
| ▫️ | ▫️ | ▫️ | ▫️ |
| ▫️ | ▫️ | ▫️ | ▫️ |
| ⚪ | ⚪ | ⚪ | ⚪ |

---

## 3. ⚔️ 吃子核心法则 (The 2-vs-1 Rule)

吃子是本游戏的精髓。公式非常简单：
> **我方两子** + **直线连成一线** + **主动进攻** = **💥 吃掉敌方一子**

你需要形成 **`⚫` `⚫` `⚪`** 的结构来消灭白子。

### 3.1 两种进攻方式 (Attack Modes)

我们用图解来看看如何制造这种结构：

| 方式 | 示意图 (Before ➡️ After) | 说明 |
| :--- | :--- | :--- |
| **A. 推进式**<br>(Push) | `⚫` `▫️` `⚫` `⚪`<br>⬇️<br>`▫️` `⚫` `⚫` `💥` | **后浪推前浪**<br>移动后方棋子填补空位，形成二打一。 |
| **B. 插入式**<br>(Connector) | `⚫` `▫️` `⚪`<br>⬇️<br>`⚫` `⚫` `💥` | **中心开花**<br>移动到队友和敌人之间，直接连通线路。 |

*(注：`▫️` 代表空位，`💥` 代表棋子被移除)*

---

## 4. 🛡️ 防御机制 (Defense)

并非所有 `⚫-⚫-⚪` 都能成功吃子。如果敌人阵地太坚固，或者你陷入包围，攻击将无效。

| 场景 | 示意图 | 判定结果 | 解析 |
| :--- | :--- | :--- | :--- |
| **坚守保护**<br>(Wall) | `⚫` `⚫` `⚪` `⚪` | ❌ **攻击无效** | **敌人太厚了**<br>敌方背后还有一子支撑 (`⚪-⚪`)，你的二打一无法击穿防线。 |
| **反包围保护**<br>(Backstab) | `⚪` `⚫` `⚫` `⚪` | ❌ **攻击无效** | **后背受敌**<br>你在进攻的同时，自己也被包围了 (`⚪- ... -⚪`)，进攻自动失效。 |

**场景一：纵向泰山压顶**

| 初始状态 | 你的动作 | 最终结果 |
| :---: | :---: | :---: |
| **⚫** `▫️` **⚪** | ➡️ **移动** | **⚫** **⚫** 💥 |

### 5.2 ❌ 常见误区与特殊规则

**场景三：对角线无效**
*斜向连线无法触发吃子*

| 状态 | 判定 |
| :---: | :--- |
| ⚫<br>　⚫<br>　　⚪ | ❌ **无效**<br>游戏只认可 **水平** 或 **垂直** 方向的战线。<br>斜向虽然好看，但没有任何威力。 |

**场景四：被动安全 (不会自杀)**
*主动权法则：只有**移动方**才能触发吃子。*

| 状态 | 你的动作 | 结果 |
| :---: | :---: | :--- |
| **⚪**<br>**⚪**<br>▫️ | ⬆️ **移动**<br>黑子主动走进虎口 | **⚫** (安全)<br>**⚪**<br>**⚪** |
| **说明** | 即使形成了 `⚪-⚪-⚫`，但因为是你（黑方）移动的，**你不会吃掉你自己**。<br>直到**下一回合**白方主动移动，你才会有危险。 | |

**场景五：墙角杀 (Corner Trap)**
*墙壁不是棋子，不会提供"坚守保护"。*

| 状态 | 你的动作 | 结果 |
| :---: | :---: | :--- |
| **⚫**<br>**⚫**<br>**⚪** | ➡️ **挤压** | **⚫**<br>**⚫**<br>💥 |
| **说明** | 即使白子紧贴墙壁，依然会被吃掉。**墙壁不会保护它**。 | |

## 6. 🧠 必胜策略：铁钳战术 (The Iron Pincer)

当你拥有三枚棋子时，可以构建出令对手绝望的 **L型包围网**。

**阵型图解**:
```text
      ⚫ (A)
      ⬇️
⚫(B) ➡️ ⚪ (敌) 
```

**战术解析**:
*   黑子 **A** 和 **B** 形成了一个直角钳子。
*   **如果白子向左跑(⬅️)**: 会撞上 B，形成 `A - B - ⚪` (被 A、B 纵向吃掉)。
*   **如果白子向上跑(⬆️)**: 会撞上 A，形成 `B - A - ⚪` (被 B、A 横向吃掉)。
*   **结论**: 只要白子落入这个夹角，就是**必死无疑**。

## 7. 🚀 新手建议

1.  **抢占中心**: 开局尽量先把棋子走到 `(1,1), (1,2), (2,1), (2,2)` 这四个格子上。
2.  **不落单**: 永远让你的棋子成对出现。单独的一个棋子没有任何威胁。
3.  **看清后路**: 在吃子前，先看一眼对方棋子的屁股后面有没有"靠山"（坚守保护）。
